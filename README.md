# Adversarial Vulnerability Auditor & Defense Framework

An end-to-end Adversarial Machine Learning research and benchmarking suite designed to analyze, exploit, and defend Convolutional Neural Networks (CNNs) against gradient-based adversarial perturbations.

The framework evaluates model vulnerability using the **Fast Gradient Sign Method (FGSM)**, implements **Adversarial Training** for defense hardening, benchmarks degradation across varying perturbation budgets ($\epsilon$), and offers an interactive **Streamlit Web Auditor** for real-time visual inspection and auditing.

## Overview

Deep neural networks achieve state-of-the-art performance on image classification, but remain susceptible to adversarial attacks such as small, human-imperceptible perturbations crafted to induce high-confidence misclassifications.

This project investigates:

1. **Vulnerability Assessment**: How susceptible are standard CNNs to one-step gradient attacks like FGSM on standard digit (MNIST) and alphanumeric (EMNIST) datasets?
2. **Defensive Hardening**: Can on-the-fly adversarial perturbation injection during training establish empirical robustness against gradient manipulation?
3. **Interactive Auditing**: Providing an intuitive UI for security researchers to visualize perturbations, observe confidence distribution shifts, and compare baseline vs. defended networks side-by-side.

---

## Key Features

- **Fast Gradient Sign Method (FGSM)**: First-order adversarial generator calculating pixel-level gradient directions that maximize classification loss.
- **Adversarial Training Pipeline**: Defends models by injecting bounded adversarial samples ($\epsilon = 0.15$) directly into the training loop.
- **Dual-Dataset Support**:
  - **MNIST**: 10 handwritten digit classes ($0-9$).
  - **EMNIST (Balanced)**: 47 alphanumeric classes ($0-9$, $A-Z$, lowercase subsets).
- **Automated Metric Benchmarking**: Comprehensive stress test evaluating accuracy across increasing perturbation strengths ($\epsilon \in [0.0, 0.30]$).
- **Interactive Streamlit GUI**:
  - Real-time noise injection and visualization.
  - Side-by-side prediction and confidence analytics.
  - Dynamic perturbation budget slider ($\epsilon$).
  - Random sample selection across test datasets.

## Mathematical Background

### Fast Gradient Sign Method (FGSM)

FGSM (Goodfellow et al., 2014) is a one-step white-box adversarial attack that leverages the gradient of the loss function with respect to the input image.

Given an input image $x$, ground-truth label $y$, loss function $\mathcal{L}(\theta, x, y)$, and perturbation budget $\epsilon$:

$$\nabla_x \mathcal{L}(\theta, x, y) = \frac{\partial \mathcal{L}(\theta, x, y)}{\partial x}$$

The adversarial image $x_{\text{adv}}$ is generated by shifting each pixel in the direction of the sign of the loss gradient:

$$x_{\text{adv}} = \text{clip}_{[0, 1]} \Big( x + \epsilon \cdot \text{sign}\big(\nabla_x \mathcal{L}(\theta, x, y)\big) \Big)$$

- **$\epsilon$ (Epsilon)**: Controls the magnitude of the perturbation. Higher values cause visible distortion, while lower values remain imperceptible to humans.
- **$\text{clip}_{[0, 1]}$**: Ensures that perturbed pixel values remain within the valid normalized image range.

### Adversarial Defense Training

Standard empirical risk minimization optimizes weights $\theta$ against clean samples:

$$\min_{\theta} \mathbb{E}_{(x, y) \sim \mathcal{D}} [\mathcal{L}(\theta, x, y)]$$

In our robust training implementation, the network optimizes its parameters against worst-case local perturbations generated dynamically during the forward-backward pass:

$$\min_{\theta} \mathbb{E}_{(x, y) \sim \mathcal{D}} [\mathcal{L}(\theta, x_{\text{adv}}, y)]$$

where $x_{\text{adv}} = \text{FGSM}(x, \epsilon_{\text{train}}, \nabla_x \mathcal{L})$ with training parameter $\epsilon_{\text{train}} = 0.15$.

## System Architecture

### Neural Network Architecture

The classifier (`DigitClassifier` in `model.py`) is a Convolutional Neural Network with dynamic head sizing for 10-class (MNIST) or 47-class (EMNIST) classification:

```
Input (1 × 28 × 28)
  │
  ├──► Conv2D (1 -> 32 filters, 3×3 kernel, padding=1) + ReLU
  ├──► MaxPool2D (2×2, stride=2) ──► (32 × 14 × 14)
  │
  ├──► Conv2D (32 -> 64 filters, 3×3 kernel, padding=1) + ReLU
  ├──► MaxPool2D (2×2, stride=2) ──► (64 × 7 × 7)
  │
  ├──► Flatten (64 × 7 × 7 = 3136 units)
  ├──► Linear (3136 -> Hidden Units) + ReLU
  │      └─ 128 units (MNIST) / 512 units (EMNIST)
  │
  └──► Linear (Hidden Units -> Num Classes) ──► Logits Output
```

## Installation & Setup

### Prerequisites

- Python 3.8+
- PyTorch 2.0+ (CUDA recommended if available, CPU supported)

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/AdversarialProject.git
cd AdversarialProject
```

### 2. Set Up a Virtual Environment (Recommended)

```bash
# Windows
python -m venv venv
venv\Scripts\activate

# Linux / macOS
python3 -m venv venv
source venv/bin/activate
```

### 3. Install Dependencies

Install the required packages using `requirements.txt`:

```bash
pip install -r requirements.txt
```

Alternatively, install them directly:

```bash
pip install torch torchvision numpy matplotlib streamlit
```

## Usage Guide

### 1. Train Baseline & Robust Models

To train both the defenseless baseline model and the adversarially hardened model on MNIST from scratch:

```bash
python main.py
```

**What this does:**

1. Downloads the MNIST dataset into `./data` (if not already present).
2. Trains the **Baseline Model** on clean samples for 3 epochs using Cross-Entropy Loss and Adam ($\text{lr} = 0.001$).
3. Trains the **Robust Model** with dynamic FGSM perturbation injection ($\epsilon = 0.15$) for 3 epochs.
4. Saves checkpoints to `baseline_model.pth` and `robust_model.pth`.
5. Evaluates both models against an FGSM attack at $\epsilon = 0.15$ and outputs a comparison showdown.

---

### 2. Generate Multi-Epsilon Robustness Curves

To test both models under increasing attack intensities ($\epsilon \in [0.0, 0.05, 0.10, 0.15, 0.20, 0.25, 0.30]$):

```bash
python plot_results.py
```

**Outputs:**

- Generates and saves `robustness_comparison.png`, visualizing accuracy degradation across both architectures.

---

### 3. Run the Interactive Web Auditor

Launch the real-time Streamlit dashboard:

```bash
streamlit run app.py
```

Once running, access the interface at `http://localhost:8501`.

#### UI Features:

- **Framework Selector**: Toggle between `MNIST (Digits Only)` and `EMNIST (Alphanumeric Mode)`.
- **Epsilon Slider**: Dynamically adjust attack intensity ($\epsilon$) from $0.00$ to $0.30$.
- **Sample Selection**: Fetch random samples from the test split to test edge cases.
- **Three-Panel Diagnostic View**:
  1. **Original Input Image**: Clean sample with initial prediction and confidence score.
  2. **Baseline Model View**: Shows the perturbed image and displays whether the defenseless model was compromised.
  3. **Robust Model View**: Shows defense resistance, predictions, and integrity status.

## Benchmarking & Empirical Results

Under an FGSM attack on MNIST with $\epsilon = 0.15$:

| Metric / Model                                       | Baseline Model (Defenseless) | Robust Model (Adversarial Training) |
| :--------------------------------------------------- | :--------------------------: | :---------------------------------: |
| **Clean Accuracy ($\epsilon = 0.0$)**                |            ~98.5%            |               ~97.8%                |
| **Accuracy under Attack ($\epsilon = 0.15$)**        |  < 30.0% (Severe collapse)   |   > 85.0% (Maintained integrity)    |
| **Accuracy under Severe Attack ($\epsilon = 0.30$)** |    < 10.0% (Random guess)    |         > 65.0% (Resilient)         |

### Observation:

- Standard models rely on non-robust features that are easily disrupted by imperceptible gradient sign shifts.
- Adversarially trained networks internalize robustness to high-gradient directions, sacrificing less than 1% clean accuracy while retaining strong performance under attack.

Potential directions for further research and expansion:
